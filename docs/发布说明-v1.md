> 版本代号：**Erwin AI Alpha 1**

## 3. 回滚方案（若上线遇严重问题）

1. **紧急回滚**：Vercel Deployments → 点上一个版本的 **Promote to Production**，5 秒内回滚；DB migration 是**向后兼容扩列**，回滚前端不会崩。
2. **若 DashScope 限流导致全部失败**：无需回滚；用户只需点「我想手工填写」即可走旧路径。
3. **若 Supabase 扩列失败**：千万不要先删列；联系数据库管理员，并临时发布前端版本把 RecommendDrawer 强制只显示手工表单（可通过注释一行 `setShowManualForm(true)` 实现）。

## 4. 监控指标（发布头 2 周必看）

无正式监控面板时，靠 Supabase SQL 每日跑 2 条即可：

### 4.1 AI 解析成功率（目标 ≥ 80%）
```sql
SELECT
  created_at::date AS dt,
  COUNT(*) AS total_requests,
  SUM(CASE WHEN (raw_extract_parse_status->>'parse_status') = 'success' THEN 1 ELSE 0 END) AS success_cnt,
  ROUND(100.0 * SUM(CASE WHEN (raw_extract_parse_status->>'parse_status') = 'success' THEN 1 ELSE 0 END) / COUNT(*), 1) AS success_pct
FROM (
  SELECT created_at,
    (CASE WHEN raw_text_snapshot IS NOT NULL THEN '"success"' ELSE COALESCE(audio_metadata->>'parse_status','"success"') END)::jsonb AS raw_extract_parse_status
  FROM user_recommendations
  WHERE source = 'ai_parsed' AND created_at >= now() - interval '14 days'
) t
GROUP BY 1 ORDER BY 1 DESC;
```

### 4.2 审核驳回类别分布（单类 >30% 触发 Prompt 优化）
直接用 `vw_reject_reason_stats`：
```sql
SELECT * FROM vw_reject_reason_stats;
```

### 4.3 三模式使用占比（目标：前 2 周语音使用率 ≥ 10% 视为用户喜爱）
```sql
SELECT input_mode, COUNT(*) cnt FROM user_recommendations
WHERE created_at >= now() - interval '7 days' GROUP BY 1 ORDER BY 2 DESC;
```
