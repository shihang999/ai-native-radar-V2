## 一、资源类型（冻结三类，永久固定）
对应 `resources.resource_type` / `user_recommendations.resource_type`

| ID (英文值，数据库写入值) | 中文名称 | 说明 |
|---|---|---|
| `book` | 书籍 | 图书、电子书、纸质书、出版社正式出版物 |
| `course` | 课程 | 网课、训练营、专题课、系列学习栏目 |
| `article` | 文章 | 长文、公众号文章、博客、报告（短内容） |

- 模型必须返回以上三选一；未识别到则返回 `null`，前端预览默认 `book`。
- DB 层有 CHECK 约束强保护：`resource_type IN ('book','course','article')`。

## 四、推荐指数 Rating（1~5）
模型返回整数，前端下拉和后端校验均强制 `1|2|3|4|5`，未明确强弱默认 4。

| 评分 | 含义（给模型指导用） |
|---|---|
| 5 | 强烈推荐 / 必读 / 神级 / 五星 |
| 4 | 推荐 / 很不错 / 适合入门 / 值得一读（默认） |
| 3 | 可以看看 / 还行 / 有启发 |
| 2 | 一般 / 仅特定人群可看 |
| 1 | 不推荐（不作为推荐条目入库，模型遇到负面评价直接跳过不进 items） |

## 五、录入模式 input_mode（提交入库用）
| 值 | 含义 |
|---|---|
| `text` | 粘贴自然语言文本 → AI 解析 |
| `image` | 上传聊天截图/书单图片 → 多模态 VL 解析 |
| `voice` | 语音口述 → ASR 转文字 → AI 解析 |
| `manual` | 用户点击「我想手工填写」的旧表单路径 |

---

## 六、提交来源 source（审核端用）
| 值 | 含义 |
|---|---|
| `ai_parsed` | 由 AI 结构化解析后提交（text/image/voice 三模式均属于此） |
| `manual` | 用户手工填写旧表单 |

---

## 七、驳回原因分类 reject_reason_category（审核端统计用）
| 分类值 | 说明 |
|---|---|
| `insufficient_info` | 信息不足：无书名、无链接、理由太短、字段缺失严重 |
| `wrong_fields` | 字段错误：领域、阶段、类型明显分错 |
| `duplicate` | 完全重复：和已上架 / 待审池内容完全一致且无新理由 |
| `low_quality` | 低质量灌水：无意义内容、广告、乱码、一句话无理由 |
| `recommender_invalid` | 昵称违规：广告语、辱骂、敏感词、冒充他人 |
| `other` | 其他驳回原因（需填写 reject_reason_detail 说明） |
