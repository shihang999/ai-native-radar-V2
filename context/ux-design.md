# UX Design Guideline | AI-Native 读书雷达

> 本文档为全产品级、跨页面通用的视觉与交互规范，适用于雷达首页、书单列表页、书籍详情页、推荐提交表单页等所有功能页面。

---

## 1. 风格关键词与可执行规则

| 关键词 | 可执行规则 |
|---|---|
| **编辑感** | 标题字号 ≥ 正文 2 倍；标题与正文之间留出 ≥ 24px 间隔；每个内容区块必须有明确的视觉起止（分隔线或 ≥ 32px 垂直留白）；禁止全宽文字块，正文最大宽度 680px |
| **克制** | 单屏可见颜色种类 ≤ 4（1 主色 + 1 强调色 + 2 中性色）；所有动效时长 150-300ms，使用 ease-out 曲线；禁止装饰性插画/图案，所有图形元素必须承载信息 |
| **信息密度分层** | 第一眼：领域颜色 + 位置（圈层/象限）传达分类与难度；第二眼：悬停/点击展开详情；第三眼：侧栏/列表页完整信息。每层信息量递增 2-3 倍，不可一次倾倒 |
| **理性可信** | 数据（推荐指数、评分人数）必须以数字形式可见，不可仅用图形暗示；所有交互操作必须可预期、可逆；避免模糊的情感化文案，使用陈述性短句 |

---

## 2. 需规避的倾向及触发原因

| 倾向 | 具体触发动作 | 为什么必须规避 |
|---|---|---|
| **电商感** | 使用价格标签式角标、进度条式评分、"热门/必读"标签、卡片阴影叠加 | 与"集体智慧筛选"的定位冲突，暗示算法推销而非理性共识 |
| **社区论坛感** | 头像+昵称+时间的组合布局、楼式回复、点赞数高亮 | 弱化内容本身，引入社交压力干扰判断 |
| **卡通化** | 圆角 > 12px 的容器、手绘风图标、拟物化书封、emoji 装饰 | 降低信息可信度，与 AI 从业者的专业预期不符 |
| **炫技式渐变发光** | 雷达 blip 使用 glow 效果、背景径向渐变、卡片 hover 发光边框 | 装饰与信息无关，干扰雷达图的视觉读取，且降低可读性 |

## 3. 色彩系统

### 3.1 基础色板

| 角色 | 色值 | 使用场景 |
|---|---|---|
| **主色（深）** | `#1A1A2E` | 页面背景、主标题 |
| **主色（浅）** | `#F7F7F8` | 内容区背景 |
| **中性色-1** | `#6B7280` | 二级文字、辅助标签 |
| **中性色-2** | `#E5E7EB` | 分隔线、禁用态 |
| **强调色** | `#E63946` | 核心操作按钮、评分高亮（唯一的高饱和强调） |

### 3.2 八大领域分类色

原则：八色必须满足色觉障碍可辨识（Sim Daltonism 测试通过），饱和度统一为中高（避免某色过于跳跃），明度拉开差异。

| 领域 | 色值 | 说明 |
|---|---|---|
| AI 工程 | `#2563EB` | 蓝——技术基底感 |
| 产品方法论 | `#7C3AED` | 紫——方法论抽象感 |
| Agent 设计 | `#0891B2` | 青——自主系统灵动 |
| 组织变革 | `#059669` | 绿——生长与变革 |
| 数据智能 | `#D97706` | 琥珀——数据价值感 |
| 商业落地 | `#DC2626` | 红——紧迫务实 |
| 伦理治理 | `#4F46E5` | 靛蓝——审慎权威 |
| 前沿趋势 | `#EC4899` | 品红——前沿先锋 |

**强制规则**：分类色仅用于标识领域归属（blip 填充、标签底色、列表页领域筛选器），禁止用于表达推荐指数高低——推荐指数由尺寸和透明度表达，见第 7 节。

### 3.3 推荐指数状态色

不使用独立色板。推荐指数通过 **同一领域色** 的透明度梯度表达：

- 5 星：opacity 1.0
- 4 星：opacity 0.8
- 3 星：opacity 0.6
- 2 星：opacity 0.4
- 1 星：opacity 0.25

理由：避免"分类"和"评分"两套色彩系统同时出现导致视觉信息过载——颜色告诉你"是什么领域"，深浅告诉你"推荐程度"。

## 4. 字体与排版规范

| 层级 | 字号 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| H1 | 32px | 700 | 1.2 | 页面主标题 |
| H2 | 24px | 600 | 1.3 | 区块标题、雷达领域名 |
| H3 | 18px | 600 | 1.4 | 卡片标题、列表项标题 |
| Body | 14px | 400 | 1.6 | 正文、描述 |
| Caption | 12px | 400 | 1.5 | 标签、辅助信息、时间戳 |

- 字体栈：西文 `Inter, -apple-system, sans-serif`；中文 `system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`
- 标题禁止使用衬线体（避免与正文风格割裂）
- 正文段间距 = 行高 × 1.5（保证扫描式阅读的节奏感）
- 数字推荐指数使用 tabular-nums 特性，保证对齐

---

## 5. 间距与网格系统

| 参数 | 值 | 说明 |
|---|---|---|
| 基础单位 | 4px | 所有间距为 4 的整数倍 |
| 内容最大宽度 | 1200px | 居中，两侧留白自适应 |
| 栅格列数 | 12 列 | 列间距 24px |
| 组件内间距 | 12px（紧凑）/ 16px（标准）/ 24px（宽松） | 按信息密度选择 |
| 区块间距 | 48px（主区块）/ 32px（次区块） | 不使用分隔线的区域靠间距分隔 |
| 雷达图容器 | 正方形，边长 = 视口宽度的 min(80vw, 680px) | 保证在移动端不会过小 |

---

## 6. 通用状态视觉语言

| 状态 | 规则 |
|---|---|
| **默认态** | 无额外装饰，blip 为实心圆（r=6px），文字无装饰 |
| **悬停态** | blip 放大至 r=10px + 出现 2px 外描边（同色系更亮）；文本链接出现下划线；过渡 200ms ease-out |
| **选中态** | 左侧出现 3px 竖线标记（主色）；背景填充主色 8% 透明度；关联元素同步高亮 |
| **加载态** | 使用骨架屏（主色 5% 透明度块），禁止旋转 spinner（与"编辑感"冲突） |
| **空态** | 居中 48px 图标（中性色）+ 一句陈述性文案（如"该领域暂无书籍"），禁止插画 |
| **错误态** | 强调色文字 + 左侧竖线标记，不使用弹窗 |

## 7. 数据可视化通用原则

### 7.1 点（blip）的处理

- 默认：实心圆，r=6px，填充所属领域分类色，透明度由推荐指数决定
- 位置含义：内圈 = 低难度入门，外圈 = 高难度进阶（与用户直觉"中心=核心"一致）
- 禁止：3D 透视、发光效果、渐变填充——纯色实心圆保证可读性
- 重叠处理：blip 间距 < 4px 时自动微偏移，并通过悬停 tooltip 完整展示

### 7.2 圈层（ring）的处理

- 描边而非填充：圈层用 1px 描边线（中性色-2），禁止扇区填充色块（干扰 blip 读取）
- 圈层标签放在圈层线外侧，12px caption 字号，不遮挡 blip
- 最外圈与容器边缘间距 ≥ 48px，留出标签空间

### 7.3 扇区（sector）的处理

- 八等分扇区之间用 1px 中性色-2 径向分隔线
- 扇区标签（领域名）放在扇区弧线中点外侧，H2 字号
- 禁止扇区填充底色——颜色信息已由 blip 承载，扇区填色会造成"双重编码"干扰

### 7.4 Tooltip（悬停详情）

- 触发：blip hover 200ms 后显示，离开即消失
- 内容：书名（H3）+ 作者（Body）+ 推荐指数（数字 + 星级符号）+ 推荐理由首句（caption，≤ 40 字截断）
- 样式：白底，8px 圆角，12px 内间距，1px 中性色-2 描边，最大宽度 280px
- 定位：优先出现在 blip 右上方，视口溢出时自动调整方向

## 8. 组件复用边界

### 全站强制统一（不可调整）

- 色彩系统（基础色板 + 领域分类色 + 透明度梯度规则）
- 字体栈与排版层级（字号/字重/行高）
- 间距基础单位（4px 倍数）与栅格系统
- 状态视觉语言（6 种状态的统一规则）
- Tooltip 样式与内容结构

### 允许页面按需调整

- 区块间距（在 32-48px 范围内根据内容密度调整）
- 卡片内间距（紧凑/标准/宽松三档自选）
- 列表页的列数（2-4 列，取决于视口宽度）
- 空态文案内容（但样式结构不变）
- 表单页的分组方式（但间距与字体不变）
