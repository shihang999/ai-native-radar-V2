# AI-Native 读书雷达 | UX 设计规范

> 本文档为全产品级、跨页面通用的视觉与交互规范，适用于雷达首页、书单列表页、书籍详情页、推荐提交表单页等所有功能页面。

---

## 1. 风格关键词与可执行规则

| 关键词 | 可执行规则 | 依据 |
|---|---|---|
| **专业信任** | 色彩克制（主色占比 70%，中性色 20%，强调色 10%），阴影采用蓝相投影，避免娱乐化高饱和渐变。 | Persona 为企业 PM/业务负责人，需传递可信、稳健的企业调性。 |
| **结构清晰** | 信息层级明确（雷达为主视觉 > 榜单卡片 > 推荐入口），留白节奏一致（模块间距 24-32px）。 | 参考 ThoughtWorks 雷达布局，降低认知负荷，支持快速判断。 |
| **重点突出** | 重点书缩略图气泡采用小范围漂浮 + 轮流高亮，普通点位保持静态，视觉权重 7:3 分配。 | 业务规则：每领域仅 4-5 本重点书展示封面，避免视觉噪音。 |
| **流畅反馈** | 交互响应时长 150-250ms（hover/focus），加载态骨架屏优先，空态友好提示而非空白。 | 提升可用性，符合 WCAG AA 标准。 |

## 2. 需规避的倾向及触发原因

| 需规避倾向 | 触发原因 | 检查点 |
|---|---|---|
| **过度装饰** | 高饱和渐变、强弹簧动效、复杂背景插图，削弱专业感，分散用户对雷达信息的注意力。 | 评审时对照 MASTER.md "Avoid" 禁区，禁止 AI 紫/粉色赛博朋克渐变。 |
| **动效喧宾夺主** | 重点书气泡大范围位移、高频跳动、脱离所属领域，影响雷达坐标判断。 | 动效必须"以雷达原始位置为中心，小范围漂浮"，用户交互时自动暂停。 |
| **伪数据填充** | 榜单卡片无真实数据时用伪数据或编辑精选补位，制造虚假热度，损害信任。 | 榜单冷启动规则：数据不足不展示，空态显示"暂无数据"提示。 |
| **低对比度文本** | 浅灰文字叠白色背景，降低可读性，不符合 WCAG AA。 | 正文主色 `#10213E`，次要文本 `#64748B`，确保对比度 > 4.5:1。 |
| **交互状态缺失** | 按钮/卡片仅设计默认态，缺少 hover/focus/active/禁用态，用户无法预判可操作性。 | 所有交互元素必须包含完整状态，遵循"通用状态视觉语言"规范。 |

## 3. 色彩系统

### 3.1 品牌独占色（来源：MASTER.md）

| 色彩角色 | Hex | CSS 变量 | 使用场景 |
|---|---|---|---|
| **Primary (主品牌色)** | `#10213E` | `--color-primary` | 章节背景、关键标题、大面积品牌色块、雷达图主边框。 |
| **Accent/CTA (强调/行动)** | `#5DB2E2` | `--color-accent` | 按钮强化、链接、图表高亮、重点书气泡高亮态。 |
| **Secondary (辅助色)** | `#625D9C` | `--color-secondary` | 辅助信息、图表辅助色、创新标签。 |
| **Success (成功态)** | `#00524C` | `--color-success` | 成功提示、正向数据增加。 |
| **Warning (警告)** | `#F59E0B` | `--color-warning` | 风险提示、关注状态。 |
| **Destructive (危险/删除)** | `#EF4444` | `--color-destructive` | 删除操作、阻断性错误。 |
| **Background (背景)** | `#FFFFFF` | `--color-background` | 工作区主背景、卡片容器底色。 |
| **Background Alt (次背景)** | `#F5F5F6` | `--color-bg-alt` | 底层过渡背景、区分模块区间。 |
| **Foreground (文本主色)** | `#10213E` | `--color-foreground` | 正文主色，替代纯黑。 |
| **Text Muted (次要文本)** | `#64748B` | `--color-text-muted` | 辅助说明、日期、图例文案。 |
| **Border (边框/分割线)** | `#E2E8F0` | `--color-border` | 卡片描边、表格网格、分割线。 |

### 3.2 分类色（八大领域，来源：DATAschema&backend-design.md）

| 领域 | Hex | 使用规则 |
|---|---|---|
| AI 工程 | `#3B82F6` | 雷达点位、扇区填充、领域标签。 |
| AI 产品与方法 | `#8B5CF6` | 同上。 |
| Agent 与智能系统 | `#EC4899` | 同上。 |
| 组织变革 | `#F59E0B` | 同上。 |
| 数据智能 | `#10B981` | 同上。 |
| 商业落地 | `#06B6D4` | 同上。 |
| 伦理治理 | `#EF4444` | 同上。 |
| AI 基础与原理 | `#6366F1` | 同上。 |

**规则：**
- 领域色仅用于雷达图可视化、筛选标签、领域标识，不用于常规按钮或背景。
- 同一领域内的所有资源点位使用相同色系，通过明度/透明度区分圈层（入门/进阶/高级）。

### 3.3 状态色（推荐指数表达）

| 推荐指数 | 表达方式 | 规则 |
|---|---|---|
| 5 星 (强烈推荐) | 实心图标 + 高亮强调色 (`#5DB2E2`) | 用于重点书气泡高亮态、Top10 徽章。 |
| 4 星 | 实心图标 + 主品牌色 (`#10213E`) | 常规推荐。 |
| 1-3 星 | 空心图标 + 次要文本色 (`#64748B`) | 不在雷达主视觉突出，仅在详情页展示。 |

**注意：** 推荐指数不与领域色混淆，通过图标形式与色彩明度区分。

## 4. 字体与排版规范

### 4.1 字体家族

```css
font-family: "MiSans", "Microsoft YaHei", "Inter", "Arial", sans-serif;
```

### 4.2 字号层级（基于 MASTER.md）

| 层级 | 字号 | 字重 | 颜色 | 行高 | 使用场景 |
|---|---|---|---|---|---|
| **Cover Title** | 48pt (48px) | SemiBold (600) | `#FFFFFF` | 1.2 | 首页英雄区大字（深色背景叠层）。 |
| **H1** | 28pt (28px) | SemiBold (600) | `#10213E` | 1.3 | 页面主标题。 |
| **H2** | 22pt (22px) | Medium (500) | `#10213E` | 1.4 | 章节标题、卡片标题。 |
| **H3** | 18pt (18px) | Medium (500) | `#1B2B47` | 1.5 | 子章节、卡片头部。 |
| **Body** | 16px | Regular (400) | `#10213E` | 1.6 | 正文、列表项。移动端基础字号。 |
| **Label/Accent** | 11pt (14px) | SemiBold (600) | `#4A9FD8` | 1.4 | 标签、强调词、大写文本。 |
| **Caption** | 12pt (12px) | Light (300) | `#64748B` | 1.5 | 注释、小字、辅助信息。 |

### 4.3 留白节奏

- 模块间距：32px（移动端 24px）。
- 卡片内边距：24px。
- 标题底部间距：H1 24px, H2 16px, H3 12px。
- 最大内容宽度：`max-width: 1440px`，阅读区文本 `max-width: 80%`（宽屏优化）。

## 5. 间距与网格系统

### 5.1 栅格系统

- **列数**：12 列。
- **列宽**：灵活（百分比）。
- **间距**：24px（桌面），16px（移动端）。

### 5.2 响应式断点

| 断点名称 | 宽度范围 | 典型布局 |
|---|---|---|
| **Mobile** | < 768px | 单列布局，筛选栏折叠为底部抽屉，雷达图全宽。 |
| **Tablet** | 768px - 1024px | 两列布局，雷达图占 8 列，榜单卡占 4 列。 |
| **Desktop** | > 1024px | 三列布局，雷达图占 8 列，榜单卡占 4 列，推荐入口固定右下角。 |
| **Wide** | > 1440px | 内容区居中，最大宽度 1440px，两侧留白。 |

### 5.3 间距 Token（Tailwind 变量）

```css
--spacing-xs: 4px;
--spacing-sm: 8px;
--spacing-md: 16px;
--spacing-lg: 24px;
--spacing-xl: 32px;
--spacing-2xl: 48px;
```

## 6. 通用状态视觉语言

### 6.1 交互元素状态

| 状态 | 视觉表达 | 动效时长 |
|---|---|---|
| **Default** | 主品牌色边框/文本，中性背景。 | - |
| **Hover** | 背景变深 5%，阴影增强，轻微上浮（`translateY(-2px)`）。 | 150ms ease-out |
| **Focus** | 蓝色轮廓环（`box-shadow: 0 0 0 2px #5DB2E2`），优先于 hover。 | 100ms |
| **Active/Pressed** | 背景变深 10%，阴影收缩，轻微下沉（`translateY(0)`）。 | 50ms |
| **Disabled** | 文本色降为 `#94A3B8`，背景 `#F1F5F9`，无交互效果。 | - |
| **Loading** | 骨架屏（灰色脉冲动画），避免 Spinner 占据大量空间。 | 循环 1.5s |

### 6.2 数据状态

| 状态 | 视觉表达 | 文案示例 |
|---|---|---|
| **Empty (空态)** | 中性插图 + 简短说明 + 引导行动（如"去推荐"）。 | "暂无内容，成为第一个推荐者"。 |
| **Error (错误)** | 警告图标 + 错误说明 + 重试按钮。 | "加载失败，请检查网络后重试"。 |
| **Success (成功)** | 成功图标 + 成功提示 + 下一步引导。 | "推荐已提交，等待审核"。 |

### 6.3 雷达图特殊状态

| 状态 | 视觉表达 |
|---|---|
| **点位默认** | 领域色圆点，直径 8px。 |
| **重点书默认** | 缩略图圆形裁切，直径 40px，轻微投影。 |
| **重点书高亮（系统轮转）** | 缩略图边框变为强调色 `#5DB2E2`，透明度 0.8，轻微放大 5%。 |
| **重点书 Hover/User Active** | 高亮暂停，缩略图边框强化（`#5DB2E2`，100%），Tooltip 显示详情。 |

## 7. 数据可视化通用原则

### 7.1 点、圈层、扇区处理规则

| 元素 | 视觉原则 | 备注 |
|---|---|---|
| **点位** | 统一大小（直径 8px），颜色按领域区分，不使用图标/文字填充。 | 避免视觉噪音，重点书例外。 |
| **圈层** | 三层同心圆（入门/进阶/高级），使用淡色填充（5% 透明度），边框 `#E2E8F0`。 | 清晰区分学习阶段，不遮挡点位。 |
| **扇区** | 领域色填充（10% 透明度），悬停时加深至 20%，边框对应领域色。 | 突出当前关注领域。 |
| **重点书缩略图气泡** | 圆形裁切，直径 40px，投影 `0 4px 12px rgba(16,33,62,0.15)`。漂浮范围：以原始位置为圆心，半径 ≤ 20px。 | 受控动效，不脱离领域。 |

### 7.2 Tooltip 信息结构

```html
<div class="tooltip">
  <h4 class="tooltip-title">书名</h4>
  <div class="tooltip-meta">
    <span class="tooltip-domain">领域标签</span>
    <span class="tooltip-rating">推荐指数: ★★★★☆</span>
  </div>
  <p class="tooltip-reason">推荐理由摘要（不超过 50 字）...</p>
</div>
```

**规则：**
- 最大宽度：240px。
- 背景：`#FFFFFF`，投影 `0 8px 24px rgba(16,33,62,0.12)`。
- 边框：`1px solid #E2E8F0`。
- 出现时机：Hover 300ms 后显示，避免误触。

### 7.3 榜单卡片

| 榜单类型 | 数据来源 | 空态处理 |
|---|---|---|
| 本周上新 | `published_at >= NOW() - 7d` | 不展示卡片。 |
| 本月最火 | `view_count_30d` 降序 | 不展示卡片。 |
| 观看最多 | `view_count` 降序 | 不展示卡片。 |
| Inspire Top 10 | `weighted_score` 降序 | 不展示卡片。 |

**视觉：** 卡片高度一致（120px），悬停时整体上浮 + 阴影增强，点击跳转资源详情。

## 8. 组件复用边界

### 8.1 强制全站统一（禁止页面级调整）

| 组件/规则 | 原因 |
|---|---|
| **色彩系统（品牌色、领域色、状态色）** | 维护品牌识别度，避免领域色混淆。 |
| **字体与字号层级** | 保证阅读体验一致性。 |
| **交互状态** | 降低学习成本，确保可访问性。 |
| **间距 Token** | 维持视觉节奏，避免零散布局。 |
| **雷达图可视化原则（点、圈层、扇区）** | 核心业务逻辑，修改需经架构评审。 |

### 8.2 允许页面按需调整

| 组件/规则 | 调整范围 | 示例 |
|---|---|---|
| **卡片圆角** | 8px - 16px | 首页榜单卡片可用 12px，详情页资源卡可用 8px。 |
| **按钮尺寸** | 遵循尺寸阶梯 | 大按钮（CTA）可用 48px 高，小按钮（次要操作）可用 36px 高。 |
| **Tooltip 内容结构** | 必须包含核心信息 | 雷达点位 Tooltip 简略，资源详情页 Tooltip 可增加作者/出版信息。 |
| **重点书气泡动效参数** | 漂浮半径、高亮节奏 | 可在 15-25px 半径范围调整，高亮周期可在 3-5s 调整。 |

---

**总结：** 本 Guideline 以"专业信任"与"结构清晰"为核心，将 ThoughtWorks 雷达的数据可视化优势与 Inspire 企业 UI 规范融合，并严格遵循已确认的业务规则（重点书展示、邀请码机制、冷启动口径）。后续所有页面设计与实现均应以此为准，评审时对照"需规避倾向"进行检查。
